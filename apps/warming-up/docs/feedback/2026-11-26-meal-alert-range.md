# 결식 알림 3~10끼

사용자가 결식 알림을 최초 최대 21끼를 요청한 뒤 최종 최대 10끼, 최소 3끼까지 설정하도록 요청했다.

- 온보딩과 더보기의 결식 알림은 3~10끼를 1끼씩 선택한다. 새 기본값은 3끼다.
- Firebase 저장 검증과 Firestore 규칙도 같은 범위를 적용한다.
- 기존 계정과 예시 모드의 1~2끼 설정은 읽을 때 3끼로 보정하고 다음 저장에 반영한다. 다른 설정은 보존한다.
- 하루 식사 시간대 수, 공복시간 주의, 건강 위험 시간은 이번 변경 범위에 포함하지 않는다.

- 예시 알림의 조회 기간도 선택한 끼니 수에 맞춘다. 하루 1끼여도 10끼 연속 미확인을 판단한다.

검증: 단위 검사 363개, 타입 검사, 개인정보 검사, 정적 빌드, 로컬 Auth·Firestore 계정/규칙 검사 5개가 통과했다. 390px 브라우저에서 온보딩·더보기의 3~10끼 선택, 키보드 경계, 저장·새로고침 복원, 기존 2끼→3끼 보정을 확인했다. 운영 게시 결과는 인계 원본에 별도로 기록한다.
