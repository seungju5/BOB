# 워밍이와 밥솥이의 짧은 반응

## 반영한 요청

워밍이는 승인된 초록 가디건 토끼 그림과 원래 첫 인사를 유지한다. 토끼를 누를 때마다 손 인사, 고개 갸웃하기, 작은 응원 점프, 감사 인사, 쉬어 가기 순서로 반응한다. 원본의 손과 연필을 하나의 관절로 움직이고 몸의 비율과 얼굴을 늘리지 않는다. 각 추가 동작은 1.9–2.6초에 끝나며 반복 재생 루프를 만들지 않는다. 말풍선은 3.2초 뒤 사라지고 재클릭 시 이전 타이머와 동작을 정리한다.

밥솥이는 보호자 홈 맨 아래의 독립 장식에서 ‘오늘의 끼니’ 카드 제목 옆의 76px 동반자로 옮겼다. 누르면 뚜껑 인사, 작은 점프, 고마운 인사, 쉬어 가기로 반응한다. 원본 그림의 뚜껑만 분리해 움직인다. 끼니 상태와 전화·기기 연결 동선은 그대로 둔다. 캐릭터의 반응과 말풍선은 식사 확인이나 기기 상태를 뜻하지 않는다.

실제 데이터를 아직 받지 못한 홈의 기존 대기 분기에만 작은 밥솥이를 표시한다. 새 로딩 페이지나 최소 대기 시간, 네트워크 지연은 추가하지 않는다. 빠른 응답에서 장식이 번쩍이지 않도록 대기 장식 자체만 CSS로 240ms 뒤 나타나며, 데이터가 도착하면 바로 본 화면으로 바뀐다.

## 접근성과 성능

- 캐릭터는 기본 button으로 구현해 터치·Enter·Space를 지원한다. 홈의 안부·전화 버튼을 가리지 않는다.
- 동작 줄이기에서는 워밍이 canvas 생성 이후 이미지 추가 다운로드·재생을 하지 않으며 원본과 말풍선을 유지한다. 밥솥이도 CSS 동작이 멈춘다.
- 워밍이는 숨긴 탭에서 프레임을 중지하고, 화면을 떠나면 타이머·프레임·이벤트를 해제한다.
- 새 패키지, 외부 이미지 요청, 오디오, 실제 데이터 추론은 없다. 기존 이미지 캐시를 사용한다.

## 검증 범위

모바일 브라우저 320/390px에서 가로 넘침 없이 끼니 카드와 전화 동선이 유지됨을 확인했다. 워밍이의 터치·키보드 반응과 동작 중 로그인 진입, 홈 밥솥이의 터치·키보드 반응을 확인했다. 실제 Android/iPhone 설치 앱이나 운영 계정 데이터 검증은 이 디자인 변경의 증거에 포함하지 않는다. 최종 자동 검사와 게시 버전은 후속 기록으로 덧붙인다.
