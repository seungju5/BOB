# 워밍이의 산책 옷장

옷을 바꿔 입으며 워밍이를 크게 보고 싶다는 의견을 반영했다. 기존에는 다른 부위로 넘어가면 직전에 입혀 본 옷이 사라졌고 일반 산책 화면에서는 예시 체험에 들어가야 옷장을 열 수 있었다.

- 보호자 메뉴와 어르신 화면의 ‘워밍이의 산책’에서 기본 옷장을 연다. 모자, 옷, 소품, 산책길을 함께 골라 걸어 본 뒤 저장한다.
- 기본 차림은 브라우저에 저장한다. 옷을 입히는 데 로그인, 걸음수 공유, 가족 데이터가 필요하지 않다.
- 하트 옷장에서는 입혀 보기가 무료다. 확정할 때 새로 사는 물건의 합계를 표시한다. 예시 체험의 가상 하트와 기본 옷장의 차림은 따로 보관한다.
- 시각 구성은 큰 아바타 아래에서 부위별 선택지를 바꿔 보는 방식을 참고했다. 밥뭇나의 워밍이 인형을 바탕으로 의상과 산책길 그림을 제작했다. [듀오링고의 아바타 편집기](https://blog.duolingo.com/ko/duolingo-avatars/)
