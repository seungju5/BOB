# 한 가구에서 시작하는 밥솥 측정

첫 가구는 평소 쓰는 실물 플러그 한 대와 알림을 받을 휴대폰 한 대로 확인합니다. 한 번의 취사가 날짜별 기록과 그 휴대폰의 잠금화면까지 도착하면 둘째, 셋째 가구를 같은 방식으로 추가합니다.

## 헤이홈 미니 플러그 연결

1. 헤이홈 앱에서 Mini를 등록하거나 이미 등록한 기기를 엽니다. 제조사는 Mini의 SmartThings 연동을 지원한다고 안내합니다. 밥솥에 연결할 때에는 제품과 밥솥의 정격 및 제조사의 고전력 기기 사용 안내도 확인합니다. [제조사 기기 안내](https://hej.life/article/%EC%83%81%ED%92%88-qa/6/109236/) · [사용 부하 안내](https://hej.life/article/%EC%83%81%ED%92%88-qa/6/92284/)
2. SmartThings의 기기 추가에서 제휴사 **Hejhome**을 선택해 같은 헤이홈 계정을 연결합니다. SmartThings에 들어온 플러그의 전력(W)과 최근 측정 시각을 확인합니다. 제조사 앱에서 이미 연결했다면 초기화할 필요가 없습니다.
3. 참여자 본인 계정의 공식 삼성 CLI에서도 새 측정을 확인할 수 있습니다. 밥뭇나 소스에서 `node scripts/export-personal-meter.mjs --only-smart-plug --fresh --out 개인점검.json`을 실행합니다. 실제 플러그가 여러 대면 `--only-smart-plug` 대신 `--device "표시 이름"`을 사용합니다. 새 W 측정이 있을 때만 로컬 파일을 남깁니다. 팀 DB와 자동 알림에 연결하는 단계는 아래를 따릅니다. [삼성의 제휴사 기기 형식](https://developer.smartthings.com/docs/devices/cloud-connected/interaction-types)

## 운영 개통과 현장 확인

| 순서 | 팀이 확인할 결과 |
| --- | --- |
| 팀 서버 | 삼성에서 팀 서비스의 시범 사용을 허용하고 등록한 콜백과 웹훅이 팀 HTTPS 서버에 도달합니다. 공개 설정의 `connectionReady`가 참이고 Web Push 공개키가 제공됩니다. 백그라운드 정기 조회와 보관 기한 정리 작업도 가동합니다. [서버 준비 절차](../../server/smartthings/README.md) |
| 가구 초대 | 팀 서버의 `SMARTTHINGS_PILOT_UIDS`에 동의한 가구의 Firebase UID만 등록합니다. 명단과 인증 정보는 공개 저장소에 쓰지 않습니다. 각 가구는 자기 밥뭇나 계정과 자기 삼성 계정으로 로그인해 자기 플러그를 선택합니다. |
| 새 신호 | 가구가 밥솥 취사 신호와 날짜별 기록을 켠 뒤 평소 취사에서 삼성 측정 시각과 밥뭇나 수신 시각을 대조합니다. 700W 이상 한 번이면 취사 신호 한 건입니다. 직전 기준 이상 측정과 10분 이내의 후속 측정은 한 건으로 묶습니다. |
| 날짜와 끼니 | 월별 기록에서 측정 날짜를 누릅니다. 설정한 1~5개 시간대 중 취사를 시작한 끼니가 표시됩니다. 시간대 밖이면 날짜별 취사 횟수에만 더합니다. 다른 가구에 같은 기록이 보이지 않는지도 확인합니다. |
| 잠금화면 | 알림 받을 휴대폰에서 밥뭇나 알림을 허용한 뒤 앱을 닫고 화면을 잠급니다. 시험 알림을 먼저 받은 뒤 평소 취사에서 자동으로 온 알림을 눌러 같은 날짜와 끼니가 열리는지 확인합니다. 아이폰은 iOS 16.4 이상에서 홈 화면에 추가한 웹앱으로 진행합니다. [Apple 안내](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/) |

휴대폰이 받았다는 증거는 잠금화면에서 관찰한 자동 알림과 그 알림으로 연 기록입니다. 팀원끼리는 익명 가구 번호와 단계별 통과 여부만 공유합니다. 이름·기기 ID·집별 생활 시각이나 원시 전력값을 저장소에 올리지 않습니다.

## 세 가구 운영 시 호출 수

가구당 플러그 한 대를 24시간 10분 간격으로 조회한다고 가정하면 전력 상태 조회는 한 가구 하루 144회, 두 가구 288회, 세 가구 432회입니다. 30일 기준 각각 4,320회, 8,640회, 12,960회입니다. 삼성 로그인·기기 목록·구독·토큰 갱신은 별도 요청이며, 실제 청구 조건은 삼성과 확인한 계약을 적용합니다.
