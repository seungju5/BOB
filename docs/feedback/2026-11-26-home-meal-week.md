# 보호자 홈 · 한 주의 밥상

## 요청과 반영

소개 화면의 ‘한 주의 밥상’ 표현을 보호자 홈의 끼니 안내에 적용한다. 월~일 요일 선택, 선택한 날의 확인 시간대 수, 작은 밥솥 심볼, 시간대별 해·달 아이콘과 상태를 한 카드로 묶었다. 따뜻한 노랑·크림·코코아 색과 기존 연락·기록·알림 동선을 유지한다.

요일 선택은 실제 화면 데이터의 날짜를 바꾼다. `오늘` 버튼은 오늘로 돌아온다. 키보드 방향키·Home·End로도 선택할 수 있다. 일반 휴대폰 폭에서는 7일을 한 줄로, 좁은 화면과 큰 글씨에서는 여러 줄로 배치한다.

## 기록 해석

- 가구별 하루 1~5개 시간대와 설정한 시간을 표시한다. 기존 첫 끼~다섯 끼 명칭을 유지한다.
- 과거 기록은 해당 날짜에 저장된 시간대 설정을 우선한다. 과거 설정이 없으면 실제 저장된 슬롯만 표시한다.
- 확인 수에는 저장된 확인·외식 상태를 반영하며 외식 포함 여부를 따로 적는다. 부재·대기·기록 없음·취사 추정은 확인 수에 더하지 않는다.
- 실제 계정의 기록 없음이나 기기 오프라인으로 미확인 판정을 새로 만들지 않는다. 미래 날짜는 예정 상태로 표시한다.
- 밥솥 사용 소식으로 실제 식사 여부나 섭취량을 단정하지 않는다. 판정 기준·알림 조건·DB 구조는 이 변경의 대상이 아니다.

## 검증

- `npm test`: 36개 파일, 372개 검사 통과 (06b77dc 이후 분리 검사). 날짜 경계·과거 설정·미연결·추정·외식·부재를 포함한다.
- `npm run check:types`, `npm run check:personal-info`, `npm run build` 통과.
- Chrome 예시 체험: 320/375/390/768/1280px에서 가로 넘침 없음. 7개 요일, 선택일 상태, 방향키·End·오늘 복귀, 200% 글씨 확대, 5끼 변경 즉시 반영을 확인했다.
- 브라우저 검수는 합성 예시만 사용했다. 실제 가구 기록, 센서 수신 또는 실기기 알림 검증을 뜻하지 않는다.
