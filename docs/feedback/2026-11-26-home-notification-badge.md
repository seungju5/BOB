# 홈 오른쪽 위 알림 숫자 배지

기존에는 미확인 개수 문구와 작은 빨간 점이 있었다. 종 아이콘 오른쪽 위에 빨간 원형 숫자 배지를 배치했다. 기존 `unackedAlerts(view)`를 그대로 사용하여 확인 또는 해제된 알림을 제외한다. 주간 리포트도 미확인 개수에 포함한다. 0개이면 배지를 숨기며, 100개 이상은 배지만 `99+`로 줄이고 버튼 문구와 접근성 이름에는 실제 개수를 유지한다. 누르면 기존 알림함으로 이동한다.
