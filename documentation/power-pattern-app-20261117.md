## 운영 데이터와 구분

SmartThings의 순간 전력값이나 변경 이벤트를 검증된 1분 평균으로 바꾸지 않는다. 실제 수집 주기·완전성·기기별 계측 오차·내부 모드 정답이 확인되지 않아 현재 자동 알림을 켜지 않는다. 기존 운영 `lib/judge`, `config/detection.ts`, Firebase/Supabase 식사 판정·보관·알림 조건은 변경하지 않는다.

연구 함수는 `modeConfirmed=false`, `confidence=null`, `eligibleForNotification=false`를 유지한다. 이 값들은 구현 실패가 아니라 검증 범위를 표현한다. 합성 검사121개 통과는 실제 밥솥 정확도100%가 아니다. 취사·재가열·세척이 같은 전력 패턴을 보이면 전력만으로 구별할 수 없고, 취사도 실제 식사 완료를 뜻하지 않는다.
