# 밥솥 소식 안부 카드 마감

기존 형식과 흐름을 지키며 밥뭇나 고유의 완성도를 높여 달라는 사용자 요청을 반영했다. 이번 범위는 `/power` 표시 계층이다.

- 승인된 크림·버터·코코아 색, Pretendard, 밥솥이 이미지로 종이 안부 카드의 테두리·여백·하단 안내를 정리했다.
- 쌀알 세 개를 본뜬 작은 SVG 장식을 추가했다. 보조기술에는 장식으로 처리한다.
- 예시·내 기록·확인 중 출처를 라벨로 분리했다. 실시간 연결이나 실제 식사를 확인했다는 뜻으로 바꾸지 않는다.
- 글씨는 상대 크기를 사용하고 헤더는 큰 글씨에서 감싸도록 했다. 주요 조작은 최소48px 높이이며, 누름 반응은 1px로 제한한다. 움직임 줄이기에서 전환과 이동을 끈다.
- 분석 과정·원시 수치·발광 배경은 다시 넣지 않았다. 기존8개 예시, 접힌 JSON 입력, 메뉴, 추정 문구, 연구 함수와 입력 계약을 유지한다.
