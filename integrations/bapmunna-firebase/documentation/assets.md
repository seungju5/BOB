`rice-half.webp`와 `rice-empty.webp`는 이번 작업에서 새로 그린 Figma 대체물이 아니다. 이전에 만든 밥 양 변형 자산을 재사용한 추가 상태다. Figma의 소복한 밥 이미지는 원본 다운로드 파일을 그대로 사용했다.

자산은 원래 비율을 유지해 표시한다. 화면 폭에 따른 슬롯 크기 조정은 CSS에서 처리한다. 로고와 브랜드 이미지는 사용자가 제공한 디자인 시안의 출처를 유지하며 공식 제휴를 새로 주장하지 않는다.

Pretendard Variable과 Nanum Pen Script는 이전 디자인의 로컬 폰트를 재사용한다. 해당 OFL 라이선스 파일을 자산 폴더에 함께 포함했다. 런타임 외부 폰트·이미지 CDN 요청은 없다.

배포되는 정적 자산과 단일 HTML은 같은 원본을 사용한다. 단일 HTML 빌드가 이미지·아이콘·폰트를 data URL로 결합하므로 내려받은 뒤 외부 Figma URL에 의존하지 않는다.
