# 현재 인사 동작 · 손과 얼굴 분리

2026-11-04 후속 수정: 얼굴·손의 늘어짐을 해결하기 위해 연속 메시를 제거하고 원본 손·연필을 독립된 조각으로 회전한다. 두 번의 점프와 그림자는 유지하고 얼굴 표정은 고정한다. [현재 구현·검증·복원 자산·생성 프롬프트](bunny-hand-fix.md)를 기준으로 한다. 아래는 이전 방식의 이력이다.

# 원본 토끼의 입체 인사 · 2026-11-04

사용자 요청: 움직임에 입체감을 조금 더 주되, 바로 이전에 승인한 토끼 그래픽과 완전히 동일하게 유지한다.

## 현재 구현

새로 그린 자세 이미지 대신 승인된 **원본 `bunny.png` 자체**를 WebGL 텍스처로 사용한다. 얼굴·털·초록 가디건·연필·클립보드는 기존 파일의 픽셀이다. 원본 SHA-256은 `87d86ce95e85f69168a6720419fd0cc3a22f32a67f13db2dea37e96e626f19f6`이며 Firebase 통합판·Next.js·Synagogue의 세 파일이 일치한다.

- 원본에 부드러운 관절 변형을 적용해 팔·귀·다리를 각각 움직인다. 연필을 든 손을 가볍게 흔들고 눈을 깜빡이며 고개를 숙인다.
- 큰 점프와 작은 점프를 그대로 유지한다. 도약·착지의 몸통 압축, 발 접기, 높이에 따라 변하는 접지 그림자가 깊이를 더한다.
- 3.6초 후 원본 `<img>`로 돌아온다. 정지 상태는 원본 그래픽이며 별도 생성 이미지로 전환되지 않는다.
- 이것은 **원본 이미지의 2.5D 변형**이다. 새 3D 모델·새로운 카메라 각도·실제 후면 텍스처를 만든 것은 아니다. 동작 중 관절 위치는 달라지지만 캐릭터를 다시 그리지 않는다.
- `object-fit:contain`의 실제 표시 영역에 맞춰 움직이는 원본의 크기와 위치를 계산한다. 기존 정적 앱과 Next.js에서 재생 시작·종료 시 크기가 튀지 않는다.
- 모션 줄이기, 숨겨진 탭 일시 정지, 중복 재생 방지, 화면 이동 시 해제는 유지한다. WebGL 미지원·컨텍스트 손실·이미지 오류 시 원본과 진입 버튼을 유지하고 재생 버튼만 숨긴다.
- 외부 라이브러리와 새 이미지 다운로드를 추가하지 않았다. 이전 `bunny-greeting.webp`는 제작 이력으로 보존하며 현재 앱은 원본을 사용한다. 구형 배포의 `spriteUrl` 인수도 화면의 원본 이미지가 우선하도록 호환한다.

## 검증

팀 단위 테스트 54개(인사 제어·원본 복원·GPU 실패·메시 뒤집힘 방지 12개 포함), Firebase의 58개 시나리오·31개 워크시트·9개 역할·8개 관리·41개 동등성/체험 검사, TypeScript, Firebase 단일 파일 빌드, Next.js Webpack 프로덕션 빌드가 통과했다. Synagogue의 58개 시나리오·31개 워크시트·9개 역할 검사와 단일 파일 빌드도 통과했다.

브라우저에서 320/390/1280px 레이아웃, 두 번의 점프·손 인사·깜빡임, 재생 중 어르신용 진입, Next.js 390px 프로덕션 화면을 확인했다. 공개 배포 버전은 `bunny-greeting-release.json`에 기록한다.

## 2026-11-03 이전 제작 이력

이전 16자세 스프라이트는 내장 image_gen으로 생성했다. 원본의 얼굴 비율과 소품에 차이가 있어 최신 사용자 요청에 따라 원본 텍스처 방식으로 교체했다. 아래 내용은 이전 제작 이력이다.

# 토끼의 깡총 인사 · 2026-11-03

사용자 요청: 사진 전체만 움직이는 효과 대신 토끼 자체가 움직이며 인사하고, 기존 깡총 점프도 유지한다.

초록 가디건·크림색 털·접힌 귀·클립보드의 원래 정체성을 참고해 16개의 실제 자세 프레임을 제작했다. 준비 → 큰 점프 → 작은 점프 → 손 흔들기 → 눈 깜빡임 → 고개 인사 → 휴식의 3.6초 동작이다. 프레임마다 다리·팔·귀·표정이 달라지며 점프 궤적은 별도로 이어진다. 2D 프레임 애니메이션이며 실시간 3D 모델은 아니다.

- 원본: docs/assets/bunny.png. 다른 화면의 정적인 동반 캐릭터와 비상 대체 이미지로 보존.
- 동작 자산: docs/assets/bunny-greeting.webp (4×4, 1254×1254, RGBA, 570674 bytes).
- SHA-256: 76891f00f8fa4602664abd2881ad346482711e100c0fe6f4ed0cb4efb6093571
- 제어: docs/bunny-greeting.mjs. Next.js 시작 화면도 같은 제어 함수를 사용한다.
- 화면당 첫 진입에 한 번 자동 재생, 다시 인사하기로 재생. 역할 선택 버튼은 계속 사용할 수 있다.
- 모션 줄이기 설정이면 자동 재생·자산 다운로드를 생략한다. 설정이 바뀌면 진행 중 동작도 중단한다.
- 숨겨진 탭에서는 일시 정지, 화면 이동 시 예약 프레임·리스너를 정리한다. 자산 로딩 오류 때는 원본 이미지가 남는다.
- 프레임의 발 위치를 보정하여 손을 흔들 때 캐릭터 전체가 좌우로 튀지 않도록 했다.
- 제작: 내장 image_gen 도구. WebP 인코딩은 기존 sharp로 크기·알파를 보존했다. 새 실행 라이브러리는 없다.
- 최종 이미지 편집 프롬프트: “Remove the background of this existing 4 by 4 bunny sprite sheet. True alpha transparency everywhere outside the 16 bunnies, with no white haze or shadows. Keep the exact same figures, poses, sizes, and grid positions. This is a transparent cutout task, not a redesign. Keep all ears and feet within each equal cell.”

자세 생성 지시: 같은 카메라·크기·조명으로 원래 토끼를 유지하고, 서기/웅크리기/도약/다리 접어 뛰기/내려오기/착지/일어서기/손 올리기/좌우 손 인사/눈 감고 웃기/고개 숙이기/손 내리기를 그린다. 4×4 동일한 셀, 셀마다 귀·발이 잘리지 않는 투명 여백을 둔다.

검증: 7개 제어 테스트(두 점프, 모션 줄이기, 로딩 실패, 늦은 응답 정리, 재생 중복 방지, 숨긴 탭 일시 정지, 설정 변경 중단), 기존 도메인·역할 테스트, 브라우저의 320/390px 재생 장면·역할 전환. 배포 증거는 공개 검증 후 별도 영수증에 기록한다.
