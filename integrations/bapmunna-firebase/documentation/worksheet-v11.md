## 명시적 실험 가정

- 원문에 지속 시간·샘플 간격의 확정값이 없다. MVP에서는 **1분 샘플·5분 지속·최대 2분 샘플 간격**을 사용하며 UI에 가정이라고 표시한다. 시간 공백은 연속성을 끊는다. 같은/과거 시각은 중복 집계하지 않는다.
- 같은 고전력 연속 구간은 취사 후보 1회다. 실제 밥솥 온도 제어·재가열 주기의 정확도는 검증하지 않았다. 오래 끊긴 측정 이후에는 새 구간이므로 실기기 정확한 취사 횟수로 해석하면 안 된다.
- 2끼·48시간·72시간은 사용자 문서의 검증 전 값이다. 오프라인·외출·공유 중지에는 미사용 추정을 하지 않고 재연결·귀가 시 관찰을 다시 시작한다. 미래 외출 취소가 이미 진행 중인 미사용 경고를 미루지는 않는다.
- 밥그릇의 양은 직접 확인 / 기기 신호 / 기록 없음의 시각 표현이다. 실제 섭취량·영양·생존·의료 상태를 나타내지 않는다.
- 모든 새 설정·요약·신호는 탭 메모리에만 있다. 새로고침하면 예시로 돌아간다. 원시 샘플 배열은 저장하지 않고 최소 분류 상태와 일별 요약만 유지한다. 실제 Firebase/Supabase 개인 식사 기록과 섞지 않는다.
