## 팀 테스트 순서

1. 공유 링크 → ‘최신 밥뭇나 열기’ → ‘보호자로 시작’에서 사용 안내를 확인한다.
2. ‘로그인 없이 데모로 둘러보기’ → ‘데모 플러그로 계속하기’로 생활 설정과 홈을 체험한다. 입력과 동의는 데모 안에서만 적용된다.
3. 기록·리포트·더보기·어르신용 전환을 확인한다. 가상 기록은 실제 가족에게 전송되지 않는다.
4. ‘내 계정’에서 Google/이메일 실제 계정을 이용한다. 데모 기록과 실제 계정 기록은 자동 합쳐지지 않는다.
5. ‘기기 연결’에서 현재 준비 상태를 확인한다. 카카오와 실제 SmartThings API 연결은 별도 등록/운영 설정이 필요하며 완료 상태로 위장하지 않는다.
